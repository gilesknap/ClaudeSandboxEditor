# MD Collaborative Editor

Local GitHub-style markdown editor shared between the user (browser) and Claude (terminal). See README.md.

- Package layout: code in `src/md_collab_editor/` (`server.py`, `static/`), installed as the `md-editor` command via `pyproject.toml` (hatchling, no dependencies). `docs/` is just a sample folder, not packaged. MIT licensed; PyPI name `md-collab-editor`. The version lives only in `src/md_collab_editor/__init__.py` (`__version__`); to release, bump it, commit, then push a matching tag (`git tag v0.1.1 && git push origin v0.1.1`); `.github/workflows/publish.yml` builds and publishes via PyPI trusted publishing and fails if the tag and `__version__` differ. PyPI never accepts a version twice.
- Run: `uv run md-editor [folder-or-file]` (or `md-editor` once installed with `uv tool install`), serves http://127.0.0.1:8765. Default document root is the current folder; the user can switch the root at runtime with the in-app file browser (`/api/root`), so check the status bar or `/api/config` for the folder currently open.
- **Collaborating on a document:** edit the `.md` file on disk directly with Edit/Write. The open editor reloads it live and flashes the change, so there is no need to go through the browser. Avoid rewriting the whole file while the user is typing; prefer targeted edits.
- Ask Claude: `ask_claude` in `server.py` runs `claude -p` (tools Skill and Read, `SYSTEM_PROMPT`). `--ask-agent` (default `uvx claude-sandbox@latest`, else `$MDEDIT_ASK_AGENT`; `none` turns it off): an argv whose basename is `claude` runs natively on pipes in `<tmp>/md-editor-ask`; anything else is a launcher, run as `<launcher> shell -c SCRIPT` (with `CLAUDE_SANDBOX_SHELL=sh`, else claude-sandbox runs SCRIPT in the user's own shell) on a PTY in ROOT, with the prompt in a 0600 `ROOT/.md-editor-ask-<hex>.txt` that SCRIPT passes to `claude` as an argument (the container's `claude` is claude-sandbox's script(1) wrapper, so `-p` gets a TTY stdin and won't read it; hence ~100 kB max). Base sessions (`ASK_BASES`, made early by `/api/ask/prepare`) hold each document version; cards fork one (`--resume --fork-session`) with a `<request>` (plus a `<document_update>` diff after small edits), Retry/Refine fork the card's returned `session`, and a failed fork falls back to one stateless call. `end_asks` ends launcher calls still running (and deletes their prompt files) when md-editor exits.
- Side-panel terminal: `TermSession` in `server.py` runs the `--agent` command (default `uvx claude-sandbox@latest`, else `$MDEDIT_AGENT`; `none` turns it off) on a PTY in ROOT. There is one shared session: it survives browser reloads (scrollback replay), doesn't follow `/api/root` changes, and its process group is killed when md-editor exits. Both agents get `child_env()`, which drops the markers a parent Claude Code session sets (`CHILD_ENV_DROP`; `CLAUDE_CODE_CHILD_SESSION` would turn off the terminal's transcript). It's served by a hand-written RFC 6455 WebSocket at `/api/term` (stdlib only). Binary frames carry PTY bytes both ways; text JSON carries `resize`/`restart` from the client and `status` from the server. On connect a running or exited session always sends one replay frame (possibly empty) after the first status: term.js relies on that to keep xterm's answers to replayed terminal queries out of the PTY. The front end is `static/term.js` (app.js only wires it up).
- Every request passes `Handler.guard` first, else 403: Host must be 127.0.0.1, localhost or [::1] (any port, so port forwarding works), and Origin, required on PUT/POST and the WebSocket, must be `http://` + Host. Test clients must send a matching Origin.
- Tests: `uv run pytest` (`tests/`, dev group in `pyproject.toml`; CI in `.github/workflows/test.yml` on 3.9 and 3.13). Each test starts real servers (`python -m md_collab_editor --port 0`, see `conftest.py`/`helpers.py`) and fails if any process they started outlives them. `tests/fakes/fake-sandbox` stands in for `uvx claude-sandbox@latest` and `tests/fakes/claude` for `claude -p` (flag files in `$FAKE_CLAUDE_STATE` make it fail or hang); `MDEDIT_ASK_TIMEOUT` shortens the 600 s Ask timeout. `test_e2e.py` drives the page with Python Playwright (3.10+, needs `uv run playwright install chromium` and CDN access), skipping without a browser unless `MD_EDITOR_E2E=require` (set in CI).
- Front end: no build step; libraries come from CDNs (marked 12, CodeMirror 5, DOMPurify, highlight.js, KaTeX, mermaid 10, github-markdown-css, Typo.js, xterm.js 5 with addon-fit and addon-web-links).
- Gotchas: DOMPurify strips attributes containing `-->` (so mermaid source is kept as element text); mermaid.render is not re-entrant (renders are queued); blur CodeMirror before calling setSelection from preview code, or its input poll re-types the selection and wipes markers. Spell checking is our own (`static/spell.js`: Typo.js plus the `dictionary-en-gb` Hunspell files from jsDelivr, suggestions in `spell-worker.js`), shown by a CodeMirror overlay; code/URL/HTML exclusions are added per line in app.js's `renderLine` handler.
